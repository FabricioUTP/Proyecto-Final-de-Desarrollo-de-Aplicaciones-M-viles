# Proyecto-Final-de-Desarrollo-de-Aplicaciones-M-viles
Este proyecto consiste en el desarrollo de una aplicación móvil multiplataforma llamada "Kronotask" orientada a la gestión de tareas dentro de un entorno empresarial. La aplicación permite a los usuarios organizar, visualizar y dar seguimiento a sus actividades diarias de manera eficiente, facilitando la productividad y el control de tareas.
